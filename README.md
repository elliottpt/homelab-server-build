# homelab-server-build
Converting an old gaming laptop into a headless Linux homelab server for IT support, networking, virtualisation, and cybersecurity practice.

## Documentation & AI Use

This project is a hands-on learning project. All hardware inspection, installation, configuration, command-line work, testing and troubleshooting documented in this repository is performed by me as part of developing my practical IT and Linux administration skills.

I use AI as a supporting tool to help structure and format my project notes into clear technical documentation, as well as to explain unfamiliar concepts and assist with troubleshooting when required. I review the resulting documentation to ensure that it accurately reflects the work I performed and that I understand the commands, technologies and troubleshooting processes described.

The aim of this project is not simply to produce a working server, but to develop a practical understanding of how a server is built, configured, administered, monitored, secured and troubleshot.
